Wiring won rentals into Google Ads

Once a rep moves an inquiry to Confirmed or Out, Closebook auto-reports it to Google Ads as a conversion carrying the booking value — matched to the ad click by the customer's hashed email/phone. Follow these steps to turn it on.

In Google Ads

1

Accept the customer data terms Google Ads console

Go to Tools & Settings → Goals → Settings → Customer data terms and accept them. This unlocks enhanced conversions for the account.

2

Turn on Enhanced Conversions for Leads Google Ads console

On that same Settings page, expand Enhanced conversions for leads, toggle it on, and choose the Google Ads API upload method.

Important: pick Google Ads API, not Google Tag / gtag.js. Closebook uploads server-side from the cron — the tag method would expect the browser to send the data and won't match our offline uploads.
3

Create the conversion action Google Ads console

Goals → Conversions → + New conversion action → Import → "Other data sources or CRMs" → "Track conversions from clicks".

  • Category: Purchase (or Qualified lead if you want to keep it separate from web purchases)
  • Value: "Use different values for each conversion" — we send the real booking amount
  • Count: One

After saving, open the action and copy its numeric Conversion action ID (the long number in the URL / details) → you'll paste it as GOOGLE_ADS_CONVERSION_ACTION_ID.

4

Get API access Google Ads + Cloud

  • Developer token — in the manager (MCC) account: API Center. → GOOGLE_ADS_DEVELOPER_TOKEN
  • OAuth client — Google Cloud console → create an OAuth 2.0 client → GOOGLE_ADS_CLIENT_ID / GOOGLE_ADS_CLIENT_SECRET
  • Refresh token — generate one for a user with access to the account (e.g. via the OAuth Playground using the https://www.googleapis.com/auth/adwords scope) → GOOGLE_ADS_REFRESH_TOKEN
  • Customer ID — the account that owns the conversion action, digits only, no dashes → GOOGLE_ADS_CUSTOMER_ID

Until all six required vars are set, the cron is a safe no-op: it logs skipped: Google Ads not configured and leaves won inquiries queued. The moment the credentials land, the next run uploads everything that's been waiting — nothing is lost.

Verify

5

Flush the queue manually

You don't have to wait for 11:00 UTC. Hit the cron endpoint with the cron secret to push whatever's queued right now:

curl -H "Authorization: Bearer $CRON_SECRET" \
  https://closebook.vercel.app/api/sync/google-ads-conversions

It returns { uploaded, failed, errors }. A clean run shows your won deals as uploaded.

6

Confirm in Google Ads

Offline imports aren't instant — conversions appear under the action within ~24–48h. Open the conversion action's Diagnostics tab to watch upload health and the email/phone match rate.

+

Later: click-level matching optional upgrade

Today matching is by hashed email/phone. For stronger, click-level attribution, capture the gclid on the /reserve form and pass it through the inquiry ingest — the column already exists and the uploader sends it automatically when present. No schema change needed.
